# SAK PWA — Revisi Laporan Saldo Awal & Saldo Akhir

Revisi ini memperjelas ringkasan laporan pada aplikasi, CSV, Excel, dan PDF.

Ringkasan laporan sekarang memuat:
- Saldo Awal: akumulasi bersih seluruh transaksi sebelum awal periode.
- Total Pemasukan: pemasukan dalam periode terpilih.
- Total Pengeluaran: pengeluaran dalam periode terpilih.
- Saldo Akhir: saldo awal + pemasukan - pengeluaran hingga akhir periode.

Istilah “Selisih” dihapus dari ringkasan laporan. Kolom ekspor menggunakan nama “Pemasukan” dan “Pengeluaran”, serta baris total bernama “Total”.

Upload isi folder `sak-pwa-main` ke root repository GitHub Pages (bukan folder induknya), lalu pastikan file `index.html`, `app.js`, `style.css`, `manifest.json`, `sw.js`, dan folder `icons` berada langsung di root.
